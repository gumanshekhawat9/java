# Student Registration Form (Java Swing)

A simple GUI application built with Java Swing that collects student
registration details and validates the input.

## Features
- Fields: Student Name, Roll Number, Gender (radio buttons), Branch
- Terms & Conditions checkbox
- Input validation with error dialogs
- Success dialog showing the submitted details
- Reset button to clear the form

## Concepts Used
- `JFrame`, `JLabel`, `JTextField`, `JRadioButton`, `ButtonGroup`,
  `JCheckBox`, `JButton`, `JOptionPane`
- Event handling with `ActionListener`
- Absolute positioning using `setBounds()`

## How to Run
    javac -d out src/StudentRegistration.java
    java -cp out StudentRegistration

## Requirements
- JDK 8 or higher
